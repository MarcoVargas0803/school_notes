<h2>Estrato:</h2> 
Conjunto de elementos que, con determinados caracteres comunes, se ha integrado con otros conjuntos previos o posteriores para la formación de una entidad o producto históricos, de una lengua, etc.
<h2>Muestreo estratificado:</h2> 
El muestreo estratificado es un método de muestreo probabilístico que divide a una población en subgrupos más pequeños llamados estratos. Estos estratos son homogéneos (similares) por dentro y diferentes entre sí. Luego, se selecciona una muestra aleatoria simple de cada estrato.
<h2>Estrato en programación:</h2>
Se refiere a una división organizada y lógica de los componentes de un sistema de software**, donde cada nivel tiene una responsabilidad única y específica.
