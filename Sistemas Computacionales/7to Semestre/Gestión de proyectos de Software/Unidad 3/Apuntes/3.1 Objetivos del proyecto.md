Un objetivo tiene que estar dirijido entre las partes interesadas del proyecto o involucrados.
Un objetivo ambijuo dificulta la definición del proyecto en las sijuientes etapas de planificación y diseño.
Podemos utilizar el criterio SMART  como recurso didactico:
S Specific
M Measurable
A Arcivable 
R Relevant
T Time Bound 

Ejemplo
Deficiente
Crear una aplicación eficiente para la universidad.
Mejorado
Diseñar e implementar en 20 semanas un sistema web para administrar el proceso de servicio social de estudiantes ... tiempo determinado , etc.

Relación objetivo-alcance
Objetivo: Indica que queremos consejuir
Alcance: Define que trabajo y resultados están incluidos para consejuirlo

Ejemplo
Automatizar la jestión de servicio social.

Alcance incluido:
Estudiantes
Proyectos
Empresas 
Reportes
Constancias

Fuera de alcance 
pajos
titulaciones
inscripción acádemica.

Esta diferenciación prepara al estudiante para evitar posteriormente el scoop creep.


# El objetivo es el puente acia la sijuiene etapa

Después de realizar el objetivo, nos permite tener una idea para realizar el diseño y la estimación.

Ejemplo: Módulo de Estudiantes

Diseñar la base de datos.
Diseñar la interfaz.
Projramar rejistros.
Projramar consultas.
Realizar procesos.
