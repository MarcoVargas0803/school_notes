# ¿Qué es un proyecto?

Esfuerzo temporal para realizar actividades para un objetivo o meta en especifico.

# ¿Cuál es el objetivo principal de la gestión de proyectos de software?

El objetivo principal es en realizar la correcta administración de los elementos principales dentro de una gestión de proyectos de software: los recursos materiales, financieros y humanos. Llevar de manera eficiente el SDLC con una correcta gestión y planificación entre las fases del mismo. 

# ¿Qué criterios se utilizan para la evaluación de personal?
Principalmente se considera el perfil profesional adecuado para el puesto, las habilidades técnicas, blandas y su experiencia.
