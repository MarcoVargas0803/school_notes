De acuerdo con Project Managment Institute. Grupo de Procesos: Guía Práctica. (2020) Se reparte en estas siguientes fases (También llamadas Grupos de Procesos):


1. [[Grupo de Procesos de Inicio]]. Procesos Realizados para definir un nuevo proyecto o nueva fase de un proyecto o nueva fase de un proyecto existente al obtener autorización para iniciar el proyecto o fase.
2. [[Grupo de Procesos de Planificación]]: Procesos requeridos para establecer el alcance del proyecto, refinar los objetivos y definir el curso de acción requerido para alcanzar los objetivos propuestos para la planificación.
3. [[Grupo de Procesos de Ejecución]]: Procesos realizados para completar el trabajo definido en el plan para la definición del proyecto a fin de satisfacer los requisitos del proyecto.
4. [[Grupo de Procesos de Monitoreo y Control]]: Procesos requeridos para hacer seguimiento, analizar y regular el progreso y desempeño del proyecto, para identificar áreas en el plan que requiera cambiar y para iniciar los cambios correspondientes.
5. [[Grupo de Procesos de Cierre]]. Procesos llevados a cabo para completar o cerrar formalmente un proyecto, fase o contrato.
