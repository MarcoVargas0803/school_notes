Para poder definir nuestros criterios de calidad desde un punto cualitativo a cuantitativo podemos basarnos de estos 5 pasos:

1. Necesidad: ¿Qué espera el usuario?
2. Objetivo: ¿Qué queremos conseguir concretamente?
3. Métrica: ¿Qué vas a medir?
4. Criterio de aceptación: ¿Cuánto es suficiente?
5. Evidencia: ¿Cómo demostramos que cumplimos?
